# أصول الإيموجي المدمجة

تستخدم مكتبة الإيموجي المرئية في ريموكيبورد مجموعة منتقاة من أصول **Noto Emoji** الرسمية، إضافة إلى خط `NotoColorEmoji.ttf` المدمج لعرض الرموز الحديثة على الأجهزة القديمة. يوفر المستودع ملفات PNG وSVG تُستخدم لبناء الخط؛ وتخضع أدوات وموارد الصور أساسًا لترخيص Apache 2.0، فيما يخضع الخط لترخيص SIL Open Font License 1.1. ستُحفظ هذه الوثيقة مع التطبيق لتوضيح المصدر والترخيص.

| العنصر | المصدر | الرابط |
| --- | --- | --- |
| صور الإيموجي المنتقاة | Google Fonts — Noto Emoji | https://github.com/googlefonts/noto-emoji |
| خط الإيموجي الملون المدمج | Google Fonts — Noto Color Emoji | https://github.com/googlefonts/noto-emoji |
| أسلوب لوحة إيموجي منفصلة | Pictograph Keyboard | https://github.com/8VIM/Pictograph-Keyboard |
| مفاتيح وظيفية خفيفة | Unexpected Keyboard | https://github.com/Julow/Unexpected-Keyboard |

يُضم عدد محدود وعملي من الصور داخل APK الأساسي بدل تنزيلها وقت التشغيل. تستمر الرموز النصية Unicode كخيار احتياطي داخل لوحة الإيموجي لضمان ظهور المحتوى حتى على الأجهزة التي لا تتوفر فيها صورة مطابقة.
