# مكتبة الإيموجي المدمجة

تعرض ريموكيبورد كامل فهرس Unicode المدمج داخل لوحة المفاتيح عبر فئات قابلة للتمرير والبحث المحلي. الفهرس يحتوي على الرموز المؤهلة بالكامل، ويستخدم خط **Noto Color Emoji** المضمّن لعرضها على الأجهزة القديمة، بما فيها Android 5.0.

يُستخدم تنظيم مألوف للفئات مثل الوجوه والأشخاص والطبيعة والطعام والسفر والرموز والأعلام، لكنه ليس واجهة واتساب ولا يتضمن صور أو أصول واتساب أو علاماتها التجارية. تنص إرشادات واتساب على عدم استخدام مواردها أو صورها خارج ما تسمح به الإرشادات أو الموافقة، بينما يسمح ترخيص SIL Open Font License 1.1 بتضمين خط Noto وتوزيعه مع البرنامج عند الاحتفاظ بنص الترخيص والإسناد.[1][2]
