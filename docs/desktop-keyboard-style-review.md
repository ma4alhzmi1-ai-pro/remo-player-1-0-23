# مواصفات استايل الكمبيوتر الكلاسيكي

## عناصر التصميم المرجعي

| العنصر | قرار ريموكيبورد |
| --- | --- |
| الحواف | إطار خارجي هادئ بلون نعناعي مع مفاتيح فاتحة وحافة رمادية دقيقة. |
| المفاتيح | مربعات مستديرة قليلًا، ظلّ داخلي خفيف، ومسافة متسقة بين الصفوف. |
| الصف العلوي | أدوات عملية صغيرة: رموز، إيموجي، ترجمة، لصق، بحث، وإعدادات. |
| المفاتيح الواسعة | حذف وShift وEnter ومسافة بعرض أكبر وفق وظيفة المفتاح. |
| التفاعل | توجيه كل مفتاح إلى `InputConnection` أو خدمة الإدخال؛ لا توجد مفاتيح شكلية. |

## المراجع والأسلوب القانوني

راجعت Hacker’s Keyboard كمثال مفتوح المصدر للصف الرقمي والأسهم وTab وCtrl وEsc. يذكر المشروع دعم هذه المفاتيح في لوحة برمجية، لكن مستودعه قديم ويشير إلى مشكلات توافق في أنظمة أندرويد الحديثة؛ لذلك لا تُستخدم شيفرته. سيعاد تنفيذ المفاتيح الملائمة فقط على طبقة `InputConnection` الحديثة الخاصة بريموكيبورد.

لا يحتاج الهاتف إلى نسخة كاملة من لوحة حاسوب فعلية، لذلك سيبقى التخطيط موجهًا للمس: صف وظائف مختصر، مفاتيح تحكم واسعة، وأسهم ضمن صف منفصل بدلاً من تصغير كل المفاتيح إلى حجم غير عملي.
