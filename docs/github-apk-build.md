# بناء ملف APK عبر GitHub

يستعمل المسار `.github/workflows/build-remo-keyboard-apk.yml` مشروع `android-ime` الأصلي فقط، وهو المشروع الذي يحتوي خدمة لوحة المفاتيح (`InputMethodService`) ويستهدف API 21. عند الدفع إلى فرع يبدأ بـ `remo-keyboard-v` أو عند تشغيل المسار يدويًا، يفحص GitHub عناصر الخدمة ثم يبني `app-debug.apk` ويضعه داخل الملف المضغوط `RemoKeyboard-1.0.5-Android-APK.zip`.

| العنصر | القيمة |
| --- | --- |
| الحد الأدنى للتوافق | Android 5.0 / API 21 |
| صيغة التسليم | ZIP يحتوي APK قابلًا للتثبيت |
| نوع البناء | Debug غير موقّع للنشر في متجر التطبيقات |
| مدة الاحتفاظ بملف البناء | 90 يومًا في GitHub Actions |

> للبناء المخصص للنشر عبر متجر Google Play، يلزم لاحقًا إنشاء مفتاح توقيع آمن وإعداد بناء Release موقع؛ لا ينبغي إدراج مفتاح التوقيع في المستودع.
