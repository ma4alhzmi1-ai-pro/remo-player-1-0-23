# مراجعة توافق Media3 / ExoPlayer

يستخدم `expo-video` محرك AndroidX Media3 / ExoPlayer بالفعل ضمن طبقة Android الأصلية. لذلك فإن إضافة الاعتماد الأساسي نفسه لا تغيّر دعم الترميزات. تفصل وثائق Android بين **امتداد الملف/الحاوية** مثل MKV أو MP4 وبين **ترميز الفيديو والصوت** الموجود داخله؛ نجاح التشغيل يتطلب دعم الاثنين.[1]

| المسار | الأثر الفعلي | القرار |
|---|---|---|
| Media3 / ExoPlayer الأساسي | يدعم الحاويات الشائعة مثل MP4 وMatroska/WebM وMPEG-TS وFLV، مع اعتماد فك الفيديو على برامج ترميز الهاتف | موجود بالفعل عبر `expo-video`؛ لا تكرار للاعتماد |
| امتداد FFmpeg الرسمي | يوسع **فك الصوت** مثل AC-3 وDTS وTrueHD وFLAC وOpus؛ لا يضيف برنامج فك فيديو عام | لا يُدمج كحل لفيديوهات غير قابلة للتشغيل |
| امتدادات AV1 وVP9 الرسمية | توفر فك فيديو برمجي محدد لـAV1/VP9 لكنها تتطلب بناءً أصلياً متوافقاً وحجم APK أكبر | يمكن تقييمها لاحقاً كخيار مستقل بعد تسجيل ترميزات الملفات المتعذرة |
| مشغل VLC / FFmpeg كامل | قد يوسع ترميزات الفيديو لكنه ليس دمج ExoPlayer، وله حجم وترخيص واختبارات دورة حياة مختلفة | لا يُدمج في هذا الإصدار بلا موافقة صريحة وخطة ترخيص/حجم |

> لا يمكن لامتداد ExoPlayer وحده أن يضمن تشغيل «كل الصيغ»، لأن الأجهزة تختلف في برامج الترميز المادية والملفات قد تستخدم ترميزاً غير مدعوم حتى مع امتداد شائع.[1]

## مسار التوافق للفيديوهات غير المدعومة

المرشح العملي لفيديوهات الترميز أو الحاوية غير المدعومة هو **LibVLC** بوصفه محرك توافق احتياطياً، لا بديلاً عاماً لـExoPlayer. يذكر VideoLAN أن libVLC يدعم عدداً واسعاً من برامج الترميز والحاويات والبث وهو مرخّص LGPL 2.1.[3] حزمة `expo-libvlc-player` ذات رخصة MIT وتوفر مكوّن Expo أصلياً، لكنها توثق توافقها المعلن مع Expo SDK 57+، فيما يعمل المشروع الحالي على SDK 54؛ لذلك يلزم بناء APK تجريبي وفحص حقيقي قبل جعلها مساراً افتراضياً.[4]

| امتداد | الحقيقة التقنية | سلوك REMO PLAYER المقترح |
|---|---|---|
| FLV | حاوية مدعومة في Media3، لكن نجاح الفيديو والصوت داخلها يبقى تابعاً للترميز | يبدأ بـExoPlayer ويستخدم LibVLC عند ظهور خطأ فك ترميز |
| MP5 | امتداد غير موحد؛ قد يكون ملف MPEG-4/H.264 مع تسمية مختلفة أو صيغة خاصة | يفهرس ويُجرب ثم يوضح رسالة الترميز عند تعذر كل المحركات |
| MVR | اسم غير موحد وقد يكون ملف كاميرا/مسجل فيديو خاصاً أو حاوية مخصصة | يفهرس ويُجرب بمحرك التوافق؛ لا يُدّعى الدعم ما لم يُقرأ الترميز |
