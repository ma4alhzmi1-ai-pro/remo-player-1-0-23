# تحقق Media3 لتحكمات الإشعار

تمت مراجعة مرجع `androidx.media3.session.CommandButton` الرسمي ومصدر Media3 المفتوح في 27 أغسطس 2026. يعرض المرجع رمزاً للسابق ورمزاً للتالي، ولذلك يستخدم التصحيح المحلي `CommandButton.ICON_PREVIOUS` و`CommandButton.ICON_NEXT` ضمن تخطيط إشعار الموسيقى.

المصدر: <https://developer.android.com/reference/androidx/media3/session/CommandButton> و<https://github.com/androidx/media/blob/release/libraries/session/src/main/java/androidx/media3/session/CommandButton.java>.
