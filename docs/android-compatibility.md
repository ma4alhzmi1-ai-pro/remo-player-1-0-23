# توافق Android في REMO PLAYER

تدعم نسخة REMO PLAYER الحالية **Android 7.0 (API 24) فما فوق**. هذا الحد ليس اختياراً شكلياً؛ فالإصدار المستخدم من React Native يعرّف `minSdk` بقيمة 24، كما تعتمد ميزات التطبيق على حزم وسائط حديثة مثل تشغيل الفيديو والصوت، اختيار الملفات، فهرسة الوسائط، المشاركة، والحافظة.

يستهدف التطبيق **Android 16 (API 36)** لضمان توافقه مع أحدث متطلبات المنصة، مع الحفاظ على تشغيله على الإصدارات المدعومة من Android 7.0 وما بعدها. جرى أيضاً تضمين معماريتي `armeabi-v7a` و`arm64-v8a` لتغطية غالبية الهواتف المدعومة.

> لا يمكن جعل الحزمة الحالية تعمل بأمان على Android 4.4 (API 19) إلى Android 6.0 (API 23) بمجرد خفض `minSdkVersion`. يتطلب ذلك مشروعاً منفصلاً مبنياً بأدوات ونسخ React Native أقدم، مع تقليل ميزات تشغيل الوسائط والذكاء الاصطناعي والملفات الحديثة، واختباره كمنتج مستقل.

## خيار الأجهزة القديمة

إن كانت الأجهزة القديمة أولوية، فالنهج المناسب هو إصدار **REMO PLAYER Legacy** مستقل يدعم Android 4.4–6.0، بوظائف محلية أساسية فقط: فهرسة الصوت والفيديو، تشغيل الملفات المتوافقة، وقوائم تشغيل بسيطة. لا ينبغي مشاركة حزمة REMO PLAYER الحديثة معه، لأن مكتباتها الأصلية تتطلب Android 7.0 أو أحدث.
