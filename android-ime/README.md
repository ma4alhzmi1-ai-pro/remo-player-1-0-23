# ريموكيبورد مزخرف — طبقة Android IME الأصلية

هذا المجلد مشروع أندرويد أصلي صغير مستقل عن واجهة إدارة Expo. يحتوي على خدمة `InputMethodService` الفعلية التي يمكن اختيارها من إعدادات لوحة المفاتيح في أندرويد، ويستهدف **Android 5.0 / API 21** كحد أدنى من دون مكتبات طرف ثالث لتقليل حجم الحزمة وتعقيدها.

| المكوّن | الغرض |
| --- | --- |
| `RemoInputMethodService` | إدخال النص والحذف والمسافة وتنفيذ زر التالي/الإدخال والميكروفون والحافظة. |
| `RemoKeyboardView` | مفاتيح عربية وإنجليزية وأرقام ورموز، واقتراحات وأدوات وزخرفة وضغط مطول. |
| `KeyboardSettingsActivity` | تفعيل لوحة المفاتيح واختيارها ومنح إذن الميكروفون واختيار الثيم والأرقام. |
| `ClipboardRepository` | حفظ عناصر الحافظة على الجهاز بحد عددي قابل للضبط من دون تقصير للنص نفسه. |

## البناء

افتح مجلد `android-ime` في Android Studio حديث، واتركه يحمّل Android SDK Platform 35، ثم نفّذ بناء نسخة Debug من قائمة **Build**. بعد تثبيت الحزمة على جهاز أو محاكي يعمل بـ API 21 أو أعلى، افتح «ريموكيبورد مزخرف»، واضغط خطوة التفعيل ثم اختر اللوحة من مُبدّل لوحات المفاتيح في النظام.

> ميزة الصوت تستعمل محرك التعرف الصوتي المتوفر في الجهاز. يمكن أن تختلف دقة التحويل بين الأجهزة واللهجات وجودة الميكروفون أو إعدادات الخدمات، لذلك لا تقدم الخدمة وعدًا بدقة مطابقة حرفيًا في جميع الحالات.

## اختبار البنية

من جذر المشروع نفّذ `node scripts/check-native-ime.mjs`. يتحقق الاختبار من إعداد API 21، وتعريف خدمة IME، ومسارات الأزرار والحافظة والصوت واللغات والتشكيل.
